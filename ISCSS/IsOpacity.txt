CSS Opacity

- opacity controls how transparent an element is (0 to 1).
- lower opacity affects the entire element, including text and children.
- use RGBA backgrounds to fade the background only.

Why use opacity
- Create hover fades on images or cards.
- Build layered UI effects and overlays.

Simple example
```
.card { opacity: 0.8; }
.card:hover { opacity: 1; }
.overlay { background: rgba(0, 0, 0, 0.4); }
```
