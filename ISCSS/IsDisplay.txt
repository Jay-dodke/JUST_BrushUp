CSS Display

- Display tells how an element sits on the page.
- It changes line breaks and size behavior.

Main types
- block: starts on a new line and takes full width.
- inline: stays on the same line and fits its text.
- inline-block: stays on one line but keeps width and height.
- none: hides the element and removes its space.
- visibility hidden: hides the element but keeps its space.

Simple example
```
.block { display: block; }
.inline { display: inline; }
.inline-block { display: inline-block; width: 120px; height: 60px; }
.none { display: none; }
.hidden { visibility: hidden; }
```
