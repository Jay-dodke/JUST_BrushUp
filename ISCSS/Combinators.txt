Combinators

- descendant (space) selects any element inside another.
- child (>) selects only direct children.
- adjacent sibling (+) selects the next sibling only.
- general sibling (~) selects all following siblings.

Why use combinators
- Target elements based on structure without adding extra classes.
- Keep HTML cleaner and styles more focused.

Simple example
```
section p { color: #333; }
ul > li { font-weight: bold; }
h2 + p { margin-top: 0; }
h2 ~ p { color: #666; }
```
