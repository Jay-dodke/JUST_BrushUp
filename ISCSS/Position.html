CSS Position

The position property controls how an element is placed in the layout.

Static (default)

Static elements follow normal flow and ignore offsets.

Static box
Normal box

Relative

Relative elements keep their space but can be nudged with offsets.

Relative box
Normal box

Absolute (inside a relative parent)

Absolute elements are positioned inside the nearest positioned ancestor (non-static) and are removed from normal flow. If no positioned ancestor exists, they use the document body.

Relative parent
Absolute box

Fixed (viewport)

Fixed elements are positioned relative to the viewport, stay in place on scroll, and do not leave a gap. Use top/right/bottom/left to place them. See the fixed badge at bottom-right.

Sticky (inside a scroll area)

Sticky elements act like relative until a scroll point, then stick. You must set at least one offset (like top).
