CSS Position

- static is the default; elements follow normal flow.
- relative keeps its space but can be offset with top/left.
- absolute is removed from flow and positioned inside the nearest positioned parent.
- fixed is anchored to the viewport, stays on scroll, and leaves no gap.
- sticky behaves like relative until it reaches a scroll position, then sticks.
- sticky needs at least one offset (top/right/bottom/left) to work.

Why use position
- Create overlays, badges, and tooltips.
- Place UI elements like headers or floating buttons.
- Control layout in special cases without changing flow.

Simple example
```
.relative-parent { position: relative; }
.absolute-box { position: absolute; top: 10px; right: 10px; }
.fixed-badge { position: fixed; bottom: 16px; right: 16px; }
.sticky-bar { position: sticky; top: 0; }
```
