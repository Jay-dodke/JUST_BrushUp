CSS Overflow

The overflow property controls what happens when content is too big for a box.

Overflow: hidden

Extra content is clipped.

Hidden content. This text is longer than the box so it gets cut off.

Overflow: scroll

Scrollbars are always visible.

Scroll inside this box to read more content. Lorem ipsum dolor sit amet, consectetur adipiscing elit. Donec varius nisi a risus tincidunt, sed luctus lorem facilisis.

Overflow: auto

Scrollbars appear only when needed.

Auto content. This text will overflow and show scrollbars only if required by the content size.

Overflow-x and Overflow-y

Control horizontal and vertical overflow separately.

This box has a long line that forces horizontal scrolling: super-long-line-super-long-line-super-long-line-super-long-line.
