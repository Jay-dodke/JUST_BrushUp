CSS Pseudo-Classes

- pseudo-classes style elements by state or position.
- interactive: :hover, :focus, :active, :visited, :link.
- form state: :required, :valid, :invalid.
- structural: :first-child, :last-child, :nth-child().

Why use pseudo-classes
- Add professional UI feedback without extra HTML.
- Highlight items based on position in a list.

Real life example
- Navigation links with hover and active states.
- A sign-up form that shows valid/invalid fields.
- A pricing list where every other row is shaded.

Simple example
```
a:hover { color: #fff; background: #2b4c7e; }
input:focus { outline: 3px solid #f0b35e; }
li:nth-child(2n) { background: #f7faff; }
```
