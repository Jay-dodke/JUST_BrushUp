Flexbox Container

- the flex container is the parent element with display: flex.
- it controls the layout of its direct children (flex items).

Key container properties
- flex-direction: row | row-reverse | column | column-reverse
- flex-wrap: nowrap | wrap | wrap-reverse
- flex-flow: shorthand for direction and wrap
- justify-content: alignment on the main axis
- align-items: alignment on the cross axis
- align-content: spacing between lines (only when wrapping)
- gap: spacing between items

Why this example is useful
- shows wrapping into multiple lines with consistent spacing.
- demonstrates main-axis and cross-axis alignment together.
- uses align-content so multi-line rows distribute evenly.

Simple example
```
.flex-container {
  display: flex;
  flex-direction: row;
  flex-wrap: wrap;
  justify-content: space-between;
  align-items: center;
  align-content: space-between;
  gap: 16px;
}
```
