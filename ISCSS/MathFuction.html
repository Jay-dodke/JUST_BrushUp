CSS Math Functions

Math functions like calc(), min(), max(), and clamp() create flexible values that adapt to different screens.

calc()

Combine units with +, -, *, and / to calculate sizes.

width: calc(100% - 120px)

max()

Pick the larger value from a list.

width: max(50%, 320px)

min()

Pick the smaller value from a list.

width: min(60%, 360px)

clamp()

Keep sizes between a minimum and maximum while scaling smoothly.
