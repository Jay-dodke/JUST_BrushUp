Flexbox align-items

- align-items controls how items line up on the cross axis.
- the cross axis is vertical for a row and horizontal for a column.

Values shown
- stretch: items stretch to fill the container height (default)
- center: items centered on the cross axis
- flex-start: items aligned at the start
- flex-end: items aligned at the end
- baseline: text baselines line up

Why this example is real
- different card heights simulate real content blocks.
- baseline uses prices to show text alignment across cards.

Simple example
```
.flex-container {
  display: flex;
  align-items: center;
}
```
