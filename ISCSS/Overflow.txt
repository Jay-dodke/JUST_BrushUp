CSS Overflow

- overflow controls what happens when content is too large for a box.
- hidden clips extra content.
- scroll always shows scrollbars.
- auto shows scrollbars only when needed.
- overflow-x and overflow-y control horizontal and vertical overflow separately.

Why use overflow
- Prevent layout breakage.
- Create scrollable areas like menus or code blocks.

Simple example
```
.box { width: 240px; height: 80px; }
.hidden { overflow: hidden; }
.auto { overflow: auto; }
.x-only { overflow-x: auto; overflow-y: hidden; }
```
