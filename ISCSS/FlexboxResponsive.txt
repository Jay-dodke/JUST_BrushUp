Responsive Flexbox (Image Gallery)

- use flexbox with flex-wrap to allow items to wrap into new rows.
- change the flex-basis at breakpoints to control columns.

Key idea (from W3Schools example)
- set the container to display: flex and flex-wrap: wrap.
- set each item to a percentage of the row.
- use media queries to switch to fewer columns on smaller screens.

Simple example
```
.gallery { display: flex; flex-wrap: wrap; }
.card { flex: 25%; }
@media (max-width: 900px) { .card { flex: 50%; } }
@media (max-width: 600px) { .card { flex: 100%; } }
```
