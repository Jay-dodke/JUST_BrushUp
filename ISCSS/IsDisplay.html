CSS Display

The display property changes how an element takes space on the page.

Display: block

Block elements start on a new line and take full width.

Display: inline

Inline elements stay on the same line and fit the text.

Display: inline-block

Inline-block stays on one line but keeps width and height.

Display: none

The hidden box takes no space at all.

Visibility: hidden

The hidden box is invisible but still keeps its space.
