CSS Grid Layouts

- CSS Grid is a two-dimensional layout system for rows and columns.
- a grid container is created with display: grid.
- grid-template-areas let you name regions and place items easily.

Why use grid
- build full-page layouts with fewer wrappers.
- control rows and columns at the same time.
- make responsive layouts with media queries.

Simple example
```
.grid {
  display: grid;
  grid-template-columns: 1.5fr 3fr 1.5fr;
  grid-template-areas:
    "header header header"
    "nav main sidebar"
    "footer footer footer";
}
```
