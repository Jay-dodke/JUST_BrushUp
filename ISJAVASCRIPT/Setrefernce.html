JavaScript Set Reference

Understand shared reference vs copied Set values.

Explain

If two variables point to the same Set, both reflect the same changes. Create a new Set with new Set(oldSet) to make a copy.

Example


const setA = new Set([1, 2, 3]);
const sameSet = setA;
sameSet.add(4); // setA also changes

const copiedSet = new Set(setA);
copiedSet.add(5); // setA does not change
