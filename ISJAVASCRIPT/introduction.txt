JavaScript Introduction (summary based on W3Schools)

1) What JavaScript is
JavaScript is the programming language of the web. It runs in the browser and
lets you make pages interactive instead of static.

2) What JavaScript can do
- Calculate, manipulate, and validate data.
- Update and change HTML content.
- Change HTML attribute values (for example, an image src).
- Change CSS styles for elements.
- Hide or show elements by changing their display style.

3) How it fits with HTML and CSS
- HTML provides structure and content.
- CSS controls layout and visual design.
- JavaScript controls behavior and interaction.

4) Small example idea (matches the page you have)
Use JavaScript to listen for a button click and then write the current date/time
into a text element. This shows DOM access and updating content.

5) Quick history note
JavaScript is not Java. They are different languages. JavaScript was created by
Brendan Eich in 1995 and became an ECMA standard in 1997. The official standard
name is ECMAScript (ECMA-262).
