JavaScript Strings (simple notes based on W3Schools)

1) String Basics
Use single quotes, double quotes, or backticks to store text.
Example: "Jay" + " " + "Kumar"

2) Template Literals
Use backticks and ${} to insert variables.
Example: `Today is day ${day}`

3) Common Methods
length, trim(), toUpperCase(), slice(), replace()

4) Search in Strings
includes(), indexOf(), startsWith(), endsWith(), match()

5) Quick Reference
charAt(), at(), concat(), split(), substring(), repeat()
