JavaScript Temporal

Concept-first guide: Temporal basics, Date vs Temporal, PlainDate, and arithmetic.

Why Temporal?

  • Immutable objects (safer than mutating Date).
  • Clear types: PlainDate, Instant, ZonedDateTime.
  • Strict parsing and better timezone handling.

Temporal vs Date (Quick)


Date month index: 0-based (Jan = 0)
Temporal month index: 1-based (Jan = 1)

Date can mix local timezone behavior.
Temporal separates date/time types.

Best Way Example

Use Temporal.PlainDate for date-only values and immutable arithmetic.


const d = Temporal.PlainDate.from("2026-05-01");
const nextWeek = d.add({ days: 7 });
const lastWeek = d.subtract({ days: 7 });
