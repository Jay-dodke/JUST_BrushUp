Ternary Operator (?:)

The ternary operator is a short way to write if...else. It chooses one value when a condition is true, and another value when the condition is false.

Basic Form

condition ? valueIfTrue : valueIfFalse;

Read it like: "If condition is true, use the first value, otherwise use the second value."

Simple Example

let age = 20;
let canVote = age >= 18 ? "Yes" : "No";

Example: Shipping

let total = 42;
let message = total >= 50
  ? "Free shipping"
  : "Add items for free shipping";

Click the button.

When to Use It

  • Use it for short, simple choices.
  • Keep it on one or two lines for easy reading.
  • If the logic is long, use if...else instead.
