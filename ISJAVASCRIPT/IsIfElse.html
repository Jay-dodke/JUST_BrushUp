If, Else If, Else (Simple)

Use if to test one rule. Use else if to test more rules. Use else when nothing else matches.

if (One Check)

Run code only when the rule is true.

if (score >= 60) {
  result = "Pass";
}

Click the button.

if...else (Two Choices)

Pick one of two paths.

if (isMember) {
  price = 8;
} else {
  price = 12;
}

Click the button.

if...else if...else (Many Checks)

Check rules in order and stop at the first match.

if (temp >= 85) {
  advice = "Hot";
} else if (temp >= 65) {
  advice = "Warm";
} else {
  advice = "Cool";
}

Click the button.

Real Life: Free Shipping

Decide if the order gets free shipping.
