JavaScript Map Methods

Detailed practice with set, get, has, delete, clear, size, and iteration methods.

Method Summary

  • set(key, value): Adds or updates one key-value pair.
  • get(key): Returns the value for a key.
  • has(key): Returns true if key exists.
  • delete(key): Removes a key and returns success boolean.
  • clear(): Removes all entries from a map.
  • size: Number of entries currently in the map.
  • keys(), values(), entries(), forEach(): Iteration tools.

Example 1: Basic CRUD Methods


const marks = new Map();
marks.set("Asha", 88);
marks.set("Ravi", 73);
marks.set("Asha", 92); // update

const asha = marks.get("Asha");
const hasRavi = marks.has("Ravi");
const deleted = marks.delete("Ravi");
const total = marks.size;
