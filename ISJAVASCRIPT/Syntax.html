JavaScript

Syntax, Statements, and Comments

JavaScript code is built from statements, values, operators, and comments. This page summarizes the core syntax rules and gives short, interactive examples you can try.

Syntax Basics

  • Statements are separated by semicolons (recommended).
  • JavaScript is case-sensitive: myVar and myvar are different.
  • Strings can use single or double quotes.
  • Whitespace is ignored; line breaks help readability.

Statements

A statement is an instruction. Multiple statements form a program. 

let x = 5;
let y = 6;
let z = x + y;

Expressions & Values

Blocks group statements between { and }.

  greeting = "Good day";
