Booleans & Logical Operators

A boolean is either true or false. Logical operators combine boolean values to make decisions.

Booleans

let isOpen = true;
let isClosed = false;

Click the button.

Logical Operators

  • && (AND): true only if both are true.
  • || (OR): true if at least one is true.
  • ! (NOT): flips true/false.

AND Example

let hasTicket = true;
let hasID = true;
let canEnter = hasTicket && hasID;

Click the button.

OR Example

let hasCash = false;
let hasCard = true;
let canPay = hasCash || hasCard;

Click the button.

NOT Example

let isMuted = false;
let soundOn = !isMuted;

Click the button.
