JavaScript Set Methods

Learn how to add, delete, check, and loop values in a Set.

Explain

A Set stores unique values only. Use add() to insert, has() to check, delete() to remove, and size to count values.

Example


const topics = new Set(["HTML", "CSS"]);
topics.add("JavaScript");
topics.add("CSS"); // ignored (already exists)

const hasCss = topics.has("CSS");
topics.delete("HTML");
const count = topics.size;
