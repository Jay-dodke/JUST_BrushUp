Variables, let, const, and Data Types

Variables store data you can reuse and change. JavaScript provides let and const for modern variable declarations, plus a flexible set of data types.

Variable Basics

  • Use let for values that can change.
  • Use const for values that should not be reassigned.
  • Names must start with a letter, $, or _.
  • JavaScript is case-sensitive.

Shopping Cart

const holds fixed values like tax rate, while let tracks changing totals. 

const taxRate = 0.07;
let cartTotal = 24.99;
cartTotal = cartTotal + 10.0;

Cart total: $24.99

let vs const

let can be reassigned. const cannot be reassigned, but objects declared with const can still be updated. 

let score = 10;
score = 12;

const player = { name: "Ava", points: 3 };
player.points = 4;

Data Types

JavaScript has dynamic types:

  • String, Number, BigInt, Boolean
  • Undefined, Null, Symbol
  • Object (including arrays and dates)

Real Life Example: Event Ticket

Combine types to describe an event ticket.

const eventName = "City Jazz Night";
let ticketPrice = 45;
let seatsLeft = 120;
const isSoldOut = false;
