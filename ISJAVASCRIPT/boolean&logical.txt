JavaScript Booleans and Logical Operators (simple notes based on W3Schools)

1) Booleans
A boolean is either true or false.

2) Logical operators
AND (&&): true only if both values are true.
OR (||): true if at least one value is true.
NOT (!): flips true to false and false to true.

3) Example
let hasTicket = true;
let hasID = true;
let canEnter = hasTicket && hasID;
