JavaScript Conditionals (simple notes based on W3Schools)

1) if
Run code only when the rule is true.

2) if...else
Pick one of two choices.

3) if...else if...else
Check rules in order and use the first match.

4) Conditions
Use operators like >=, <=, &&, || to build rules.

5) Real life idea
Use if/else for things like price, shipping, or access.
