JavaScript Output

JavaScript can display data in multiple ways, from updating HTML elements to logging in the console. This page recreates the core output methods with safe, interactive demos.

Display Possibilities

  • Write into an HTML element with innerHTML or innerText.
  • Write into the document with document.write() (testing only).
  • Show an alert with window.alert().
  • Log output with console.log().

Changing innerHTML is the most common way to display data in HTML.

Write to an HTML Element

Use innerHTML for markup and innerText for plain text.

document.write()

document.write() is handy for quick testing, but running it after the page loads will replace the document. 

document.write(5 + 6);

This opens a small window so the current page stays intact.

window.alert()

Alerts are immediate but interrupt the user flow.

alert(5 + 6);

console.log()

Use the browser console for debugging output.

console.log(5 + 6);

Console is idle.

Print the Page

JavaScript cannot access printers directly, but window.print() prints the current window.
