JavaScript Maps

Learn how Map stores key-value pairs with any data type as keys.

What is a Map?

A Map is a collection of key-value pairs. Unlike plain objects, Map keys can be strings, numbers, booleans, or even objects. Maps also remember insertion order.

Common Methods


const studentMarks = new Map();
studentMarks.set("Asha", 90);
studentMarks.set("Ravi", 84);
studentMarks.set("Asha", 95); // updates existing key

const ashaMarks = studentMarks.get("Asha");
const hasRavi = studentMarks.has("Ravi");
studentMarks.delete("Ravi");
const total = studentMarks.size;

Iteration Example


const prices = new Map([
  ["Pen", 10],
  ["Book", 40],
  ["Bag", 350]
]);

let line = "";
for (const [item, price] of prices) {
  line += `${item}:${price} `;
}

Object Key Example


const attendance = new Map();
const student1 = { id: 1, name: "Asha" };
const student2 = { id: 2, name: "Ravi" };

attendance.set(student1, "Present");
attendance.set(student2, "Absent");

attendance.get(student1); // Present
