JavaScript Set Logic

Use Set operations like union, intersection, and difference.

Explain

Set logic combines or compares two Sets. Union joins all values, intersection keeps common values, and difference keeps only unique values from one Set.

Example


const a = new Set([1, 2, 3, 4]);
const b = new Set([3, 4, 5, 6]);

const union = new Set([...a, ...b]);
const intersection = new Set([...a].filter((v) => b.has(v)));
const difference = new Set([...a].filter((v) => !b.has(v)));
