JavaScript Where To (summary based on W3Schools)

1) Script tag location
JavaScript code goes between <script> and </script> tags. The tags can be placed
in the <head> or in the <body>.

2) Script in the head
Place functions in the head and call them later from the body (like a button
click). This keeps code available early, but can delay rendering if heavy.

3) Script in the body
Putting scripts at the end of the body can improve page load, because the HTML
renders before the script is parsed.

4) External JavaScript
Use <script src="myScript.js"></script> to load a separate file.
Benefits:
- Clean separation of HTML and JavaScript
- Easier maintenance
- Browser caching improves load time

5) External references
You can reference a script by:
- Full URL (https://www.example.com/myScript.js)
- File path (/js/myScript.js)
- No path (myScript.js)
