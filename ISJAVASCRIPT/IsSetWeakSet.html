JavaScript WeakSet

Store object references only, with weak memory behavior.

Explain

WeakSet can only store objects. It supports add(), has(), and delete(), but cannot be iterated or counted with size.

Example


const ws = new WeakSet();
const student = { name: "Asha" };

ws.add(student);
const existsBefore = ws.has(student);
ws.delete(student);
const existsAfter = ws.has(student);
