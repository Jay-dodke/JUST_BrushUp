Switch Statement

A switch statement checks one value and matches it against different case labels. Use break to stop after a match, and default if nothing matches.

Basic Form

switch (value) {
  case "A":
    result = "Apple";
    break;
  case "B":
    result = "Banana";
    break;
  default:
    result = "Unknown";
}

Simple Example

Pick a day number and see the name.

let day = 3;
switch (day) {
  case 1:
    name = "Monday";
    break;
  case 2:
    name = "Tuesday";
    break;
  case 3:
    name = "Wednesday";
    break;
  default:
    name = "Other";
}

Real Life Example: Drink Size

Switch is handy for menus and choices.

let size = "M";
switch (size) {
  case "S":
    price = 2;
    break;
  case "M":
    price = 3;
    break;
  case "L":
    price = 4;
    break;
  default:
    price = 0;
}

Click the button.

Tips

  • Use break to stop after a match.
  • default runs if no case matches.
  • Switch compares with strict match (like ===).
