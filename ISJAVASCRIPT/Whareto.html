Where to place JavaScript in HTML

JavaScript code is placed between <script> and </script> tags. Scripts can live in the <head>, in the <body>, or be loaded from external .js files.

Script in the <head>

A function can be defined in the head and called later, for example when a user clicks a button. 

<head>
  <script>
    function myFunction() {
      document.getElementById("demo").innerHTML =
        "Paragraph changed.";
    }
  </script>
</head>

Script in the <body>

You can also place scripts near the bottom of the body for faster page rendering. 

<body>
  <button onclick="myFunction()">Try it</button>
  <script>
    function myFunction() {
      document.getElementById("demo").innerHTML =
        "Paragraph changed.";
    }
  </script>
</body>

External JavaScript

Keeping JavaScript in external files separates HTML and code, improves readability, and lets browsers cache scripts. 

<script src="myScript.js"></script>
