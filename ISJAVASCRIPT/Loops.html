JavaScript Loops: for, while, break, continue

Loops repeat code. Use for when you know the count, and use while when you loop until a condition changes.

for loop (counting)


for (let i = 1; i <= 5; i++) {
  total += i;
}

Control flow (one by one)

Loops + break/continue control the flow.


for (let i = 1; i <= 5; i++) {
  if (i === 2) continue;
  if (i === 4) break;
